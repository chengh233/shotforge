# Prompt 策略（Wan / 图生视频）

模型能力有限，**靠 prompt 的细节与结构来补**。Claude 的活儿：把用户一句话的意图
**扩写成结构化、信息量充足的提示词**——但要克制（一个清晰主运动、无自相矛盾）。

参考：Wan 官方提示词指南（[HF 复述](https://huggingface.co/blog/MonsterMMORPG/how-to-prompt-wan-models-full-tutorial-and-guide)）。

## shotforge 里有两类 prompt

### A. 起始帧 / 静帧（`content` / `frame_prompt` → Qwen/FLUX 出图）
**公式（美学在前，主体场景居中，风格收尾）：**
```
美学(光线 + 景别 + 机位角度 + 构图 + 色调/时间) + 主体(详细外貌 + 神态) + 场景 + 风格
```
- 要**具体**：不是"美女"，而是"22岁、栗棕长卷发、榛色眼、米色风衣"。
- 画风交给 `style:`（不要每条重复写）。

### B. 运动 / 运镜（`prompt`/`action` + `camera` → Wan I2V）
首帧已经定了主体/场景/风格，所以**只写"动什么 + 镜头怎么动"**：
```
运镜(camera 词条) + 运动描述(主运动 + 节奏副词 + 强度 + 物理效果/次级运动)
```
- **一个清晰的主运动**，别堆叠多个同时发生的大动作。
- **节奏副词**：缓缓 / 轻轻 / 迅速 / 骤然。
- **物理效果**让画面活：发丝被风吹动、热气升起、水花飞溅、裙摆轻摆、尘埃浮动。
- **别**在运动 prompt 里重复描述静态外貌（首帧已有）。
- **别**写自相矛盾的运动（"静止不动"又"快速奔跑"）。
- 快动作模型容易糊/变形 → **能放缓就放缓**，靠多镜快切营造速度，而非单镜暴力运动。

## 例子
**起始帧（中文，喂 Qwen）：**
> 暖色边缘光，中近景，平视，左重构图，黄昏暖色调；一位疲惫的年轻女子靠在夜间电车车窗旁，神情怅惘；车厢昏黄、窗外霓虹；京阿尼动画风格。

**运动（中文，喂 Wan I2V，首帧=上图）：**
> 镜头缓缓推近（push_in）；她极轻地眨了一下眼、嘴唇微动像在低语，发丝随车身轻轻晃动，窗外霓虹光斑在她脸上缓缓流过。

## 语言侧注意
- **Wan 运动 prompt**：umT5 多语种，中文 OK。
- **Qwen 出图**：中文很好。
- **FLUX（含 FLUX LoRA 出帧）**：T5 偏英文 → frame_prompt 用英文更佳。
- **负面词**：固定一串质量/瑕疵负面（畸形手脸、多余肢体、水印文字、模糊），放 `defaults.negative` 或 `style.negative`，不必每镜写。
