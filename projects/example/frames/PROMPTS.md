# 《夜班》起始帧出图提示词

每个镜头需要**一张**起始帧 PNG。用 Dreamina / 即梦 / 任意文生图工具，按
**9:16 竖屏**生成，命名为对应文件名放进本目录（`frames/`）。

约定：
- **比例必须 9:16**（例如出图 720×1280 或 1080×1920）。渲染时图会被缩放到
  `project.yaml` 里的 `width×height`（默认 480×832 也是 9:16），比例对得上才不会被拉伸。
- 这四张图是同一个人物、同一场景的连贯故事，**尽量让女主的长相/发型/服装在
  s1–s3 保持一致**（出图时可固定同一组人物描述或用同一参考图）。
- 起始帧只决定「画面长什么样」；「画面怎么动」由 `project.yaml` 的 prompt 控制。

人物设定（贴在每条提示词前，保持一致）：
> 30岁左右亚洲女性，齐肩黑色直发，米色针织衫，神情疲惫；电影感，冷色调，9:16 竖构图

---

## s1.png — 深夜办公室·抬头
```
深夜空荡的开放式办公室，只亮着一盏暖色台灯。一位30岁左右的亚洲女性，齐肩黑发，
穿米色针织衫，独自坐在工位前，手撑下巴，疲惫地看着电脑屏幕。窗外是虚化的城市夜景灯火。
电影感，冷色调，浅景深，9:16 竖构图。
```

## s2.png — 手机屏幕特写
```

冷蓝色的屏幕光打在手指和女主的脸上，背景是虚化的办公室。情绪：震惊。
电影感，浅景深，9:16 竖构图。
```
