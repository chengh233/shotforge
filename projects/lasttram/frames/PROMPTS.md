# 《末班电车》起始帧出图提示词

6 张起始帧，日系动漫风格，**9:16 竖屏**，命名 `s1.jpeg`~`s6.jpeg` 放进本目录。

## 统一设定（每张都带上，保证人物/场景一致）
> **风格**：日系动漫赛璐璐上色，干净通透，电影感，柔和光影。
> **人物**：约 18 岁少女，黑色齐耳短发（波波头），米色风衣 + 浅色围巾，清澈的眼睛，
> 五官清秀。**六张必须是同一个人**（用即梦/Dreamina「角色」一致性功能或同一参考图）。
> **场景**：同一节夜行电车车厢——蓝灰色座椅、暖黄色车顶灯、大扇车窗，窗外是城市夜景。
> **构图**：9:16 竖构图，人物在画面下三分之一偏一侧，给车窗/天空留白。

## 情绪与光线的走向（关键——起始帧的"表情+光"决定整片的情感弧线）
s1–s3 **偏冷、疲惫、孤独**（冷蓝夜色为主）→ s4 **手机冷光打断** → s5–s6 **转暖、释然**
（暖橙光渐入）。出图时刻意让**光色和表情**跟着这条线走，反转才有力量。

---

## s1 · 拉远展开（中景偏全 · 疲惫）
```
夜行电车车厢内，少女独自靠窗坐着，肩膀微微下塌、神情疲惫；能看到一截安静空荡的车厢、
暖黄车顶灯与一排空座，窗外是暮色蓝调的城市轮廓。冷暖对比，整体偏冷清。中景偏全景，留白多。
```

## s2 · 推近侧脸（特写 · 出神）
```
少女的侧脸特写，眼神放空地望向车窗外，略带倦意；窗外流动的霓虹灯火在脸颊与发梢投下
游移的冷色光斑，浅景深，背景虚化的车厢。安静、孤独的氛围。画面只有侧脸。
```

## s3 · 靠窗（给车窗大面积 · 寂寥）
```
少女靠在车窗边，画面里车窗占较大面积，窗外是夜色中快速掠过的城市灯火、站台与树影；
她的眼神望向窗外，神情淡淡的落寞。冷蓝夜色调，构图给窗外留足空间（便于"横移"运镜）。
```

## s4 · 手机特写（转折点 · 冷光）
```
特写：少女双手捧着手机，屏幕亮起一条消息（界面简洁、不要可读真实文字）；冷蓝色屏幕光
打在她的手指和下半张脸上，她的视线落在屏幕上、神情微微一动。浅景深，背景虚化的车厢暖光。
```

## s5 · 抬头微笑（反转 · 转暖）
```
少女从手机抬起头，望向窗外，原本疲惫的神情慢慢化开，嘴角浮现一抹温柔的微笑，眼里泛起
暖意；车厢暖黄灯光柔和地打在她脸上（光色明显比前几张更暖）。近景，温柔、释然。
```

## s6 · 雨停暖光（希望 · 收尾）
```
雨停后的清透夜色，乌云裂开、暖光透过车窗洒进车厢；少女安静地望向窗外渐亮的天色，神情
释然温柔。整体暖色调、通透明亮，与前面的冷清形成对比。稍远的取景，大量留白，余韵感。
```

---

**出图小贴士**
- 六张保持**同一发型/风衣/脸**——这是转场自然的最大前提。
- 朝向连贯：s2/s3 望窗外（朝同一侧），s5 抬头朝窗，避免左右乱跳（跳轴）。
- 调好后先 `model: wan-480p` 跑通看运镜与反转节奏，满意了换 `wan`(720P) 出定稿。
- 合成加溶解+淡入淡出：`python run.py post projects/lasttram --crossfade 0.5 --fade 0.6`
